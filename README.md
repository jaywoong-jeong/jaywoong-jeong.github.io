# Jaywoong Jeong

Personal website built with Next.js 15, React 19, Tailwind CSS v4, MDX, and Motion.

Live site: [https://jaywoong-jeong.github.io](https://jaywoong-jeong.github.io)

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm ci
npm run build
```

Next.js writes the static site to `out/`.

## Deployment

Pushes to the `nim-site` branch are statically exported and deployed to GitHub Pages by [the Pages workflow](.github/workflows/pages.yml).
